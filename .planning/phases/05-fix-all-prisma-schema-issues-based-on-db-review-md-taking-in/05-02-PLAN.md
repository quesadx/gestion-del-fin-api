<objective>
Add explicit `map:` names to all 40 `@@index` directives in the Prisma schema to eliminate duplicated index names across tables, and add 4 new indexes on frequently-queried date columns. Generate a single Prisma migration and verify zero regressions with the E2E test suite.

**Purpose:** Per db-review.md §9.3, duplicated index names like `fk_person_id_idx` (appearing in 5 different tables) make `EXPLAIN` output ambiguous. Per §9.4, date columns used for filtering (`admission_requests.created_at`, `expeditions.departure_date`, `expeditions.expected_return_date`, `inventory_logs.logged_at`) have no indexes, causing full table scans on date-range queries.

**Output:** An updated schema.prisma with descriptive index names, 4 new date-column indexes, a Prisma migration, and passing E2E results.
</objective>
