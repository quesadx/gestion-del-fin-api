## Task 1: Create auth.spec.ts

Create `tests/e2e/auth.spec.ts` with login and logout E2E tests using Playwright's raw `request` (no auth fixtures needed for login):

- **POST /api/auth/login — happy path**: Valid credentials return 200 with `{ token, user }`
- **POST /api/auth/login — missing username**: Returns 400
- **POST /api/auth/login — missing password**: Returns 400
- **POST /api/auth/login — wrong password**: Returns 401
- **POST /api/auth/login — non-existent user**: Returns 401
- **POST /api/auth/logout — happy path**: Valid token returns 200, session invalidated
- **POST /api/auth/logout — no token**: Returns 401
- **POST /api/auth/logout — invalid token**: Returns 401

Use seeded users from global.setup.ts:

- username: `admin_master`, password: `test-password-123`
- username: `worker_user_1`, password: `test-password-123`

Use the assertion helpers: `expectError`, `expectEntity`.
