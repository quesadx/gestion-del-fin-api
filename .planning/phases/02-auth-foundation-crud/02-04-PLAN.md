## Task 1: Create resources.spec.ts

Create `tests/e2e/resources.spec.ts` covering all CRUD operations:

**Happy path (admin_camp1 fixture):**

- GET /api/resources → 200, returns data array with seed resources
- GET /api/resources/:id → 200, returns single resource
- POST /api/resources → 201, create resource with `{ name, unit, daily_ration, minimum_stock }`
- PUT /api/resources/:id → 200, update resource
- DELETE /api/resources/:id → 200

**Error cases:**

- GET /api/resources (no auth) → 401
- GET /api/resources/:nonexistent → 404
- POST /api/resources with missing name → 400
- POST /api/resources with duplicate name → 409
- Non-admin role (worker) trying POST /api/resources → 403

**Camp-scoped isolation:**

- admin_camp1 sees resources belonging to Camp 1
- worker_camp2 sees resources belonging to Camp 2
