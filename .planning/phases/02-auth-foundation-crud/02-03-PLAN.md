## Task 1: Create professions.spec.ts

Create `tests/e2e/professions.spec.ts` covering all CRUD operations:

**Happy path (admin_camp1 fixture):**

- GET /api/professions → 200, returns data array with seed professions
- GET /api/professions/:id → 200, returns single profession
- POST /api/professions → 201, create profession with `{ name, description }`
- PUT /api/professions/:id → 200, update profession
- DELETE /api/professions/:id → 200

**Error cases:**

- GET /api/professions (no auth) → 401
- GET /api/professions/:nonexistent → 404
- POST /api/professions with empty name → 400
- POST /api/professions with duplicate name → 409
- Non-admin role (worker) trying POST /api/professions → 403

**Camp-scoped isolation:**

- worker_camp1 sees professions belonging to Camp 1
- worker_camp2 sees professions belonging to Camp 2
