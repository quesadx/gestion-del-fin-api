## Task 1: Create camps.spec.ts

Create `tests/e2e/camps.spec.ts` covering all CRUD operations with auth and error cases:

**Happy path (admin_camp1 fixture):**

- GET /api/camps → 200, returns data array with seed camps
- GET /api/camps?page=1&limit=10 → 200, paginated
- GET /api/camps/:id → 200, returns single camp
- POST /api/camps → 201, create camp with `{ name, location, status }`
- PUT /api/camps/:id → 200, update camp name
- DELETE /api/camps/:id → 200 (or soft delete)

**Error cases:**

- GET /api/camps (no auth) → 401
- POST /api/camps (no auth) → 401
- GET /api/camps/:nonexistent → 404
- PUT /api/camps/:id with empty body → 400
- POST /api/camps with duplicate name → 409
- Non-admin role (worker) trying POST /api/camps → 403

**Camp-scoped isolation:**

- admin_camp2 fixture lists only Camp 2 resources (verifies cross-camp boundary)
